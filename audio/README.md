# Audio files

Put recorded audio here, one folder per week (`audio/week-01/`, `audio/week-02/`, …), and point to the file from the week's content:

```js
{ dar: 'bslama', ar: 'بالسلامة', en: 'bye', audio: 'audio/week-01/bslama.mp3' },
```

A file named here plays instead of the computer voice. Recordings made in the app with the 🎙 button are kept in your browser only; they play first, on that device.
